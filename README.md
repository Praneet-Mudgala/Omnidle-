# Omnidle
My first coding project. A gauntlet game with several different challenges.
There are 5 different minigames like wordle which will explain the instructions.
There is a leaderboard so you can play with your friends.
Good luck and have fun! :)

## Instructions ##
1. Go to releases pages on Github.
2. Download "Omnidle.zip".
3. Extract the zip file.
4. Run it by double clicking.

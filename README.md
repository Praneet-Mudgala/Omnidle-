# Omnidle
Omnidle is my first coding project ever created in Python. It is a text gauntlet game where you play 5 different minigames: Wordle, Poople, Hangman, Number Guessing, and Rock Paper Scissors. Each game will be explained in game if you are confused. Your goal is to gain the most amount of points possible to get a high score on the leaderboard, which saves your score so you can play with your friends as well. You can play again as much as you want. Good luck and have fun!


## Instructions ##
1. Go to release on Github.
2. Download "Omnidle.zip".
3. Extract the zip file.
4. Run it by double clicking.
